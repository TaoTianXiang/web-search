## 概念

| | 浅拷贝 | 深拷贝 |
| --- | --- | --- |
| 复制层级 | 只复制第一层 | 递归复制所有层级 |
| 嵌套对象 | 共享引用 | 完全独立 |

```js
const a = { list: [1, 2] }
const shallow = { ...a }
shallow.list.push(3)
console.log(a.list) // [1, 2, 3] —— 共享

const deep = structuredClone(a)
deep.list.push(4)
console.log(a.list) // [1, 2, 3] —— 独立
```

## 手写实现

```js
function deepClone(value, cache = new WeakMap()) {
  // 原始值与函数直接返回（函数通常不复制）
  if (value === null || typeof value !== 'object') return value

  // 循环引用：命中缓存直接返回同一副本
  if (cache.has(value)) return cache.get(value)

  // 按类型构造空壳
  let clone
  const tag = Object.prototype.toString.call(value)

  switch (tag) {
    case '[object Date]':
      clone = new Date(value.getTime())
      break
    case '[object RegExp]':
      clone = new RegExp(value.source, value.flags)
      clone.lastIndex = value.lastIndex
      break
    case '[object Map]':
      clone = new Map()
      cache.set(value, clone)
      value.forEach((v, k) => clone.set(deepClone(k, cache), deepClone(v, cache)))
      return clone
    case '[object Set]':
      clone = new Set()
      cache.set(value, clone)
      value.forEach((v) => clone.add(deepClone(v, cache)))
      return clone
    case '[object Array]':
      clone = new Array(value.length)
      break
    case '[object ArrayBuffer]':
      return value.slice(0)
    default:
      clone = Object.create(Object.getPrototypeOf(value))
  }

  cache.set(value, clone)

  // 复制自有属性，包含 Symbol 键与非枚举描述符
  Reflect.ownKeys(value).forEach((key) => {
    const desc = Object.getOwnPropertyDescriptor(value, key)
    if (!desc) return
    if ('value' in desc) {
      desc.value = deepClone(desc.value, cache)
    }
    Object.defineProperty(clone, key, desc)
  })

  return clone
}
```

必答的四个细节：

1. **循环引用**：`WeakMap` 记录"原对象 → 副本"，命中即返回
2. **特殊对象**：Date / RegExp / Map / Set 必须单独处理，否则会退化成普通对象
3. **Symbol 键**：`Object.keys` 拿不到，需用 `Reflect.ownKeys`
4. **属性描述符**：getter/setter、不可枚举属性需要 `getOwnPropertyDescriptor`

## 常见错误写法

```js
// 错误 1：JSON 往返，丢失 undefined / 函数 / Symbol / Date / 循环引用
const bad = JSON.parse(JSON.stringify(obj))

// 错误 2：只递归对象，忽略数组类型判断
function bad2(o) {
  const r = {}
  for (const k in o) r[k] = typeof o[k] === 'object' ? bad2(o[k]) : o[k]
  return r // 数组会变成普通对象
}
```

`JSON.stringify` 的具体丢失：

| 值 | 结果 |
| --- | --- |
| `undefined` / 函数 / Symbol | 属性被删除 |
| `Date` | 变字符串 |
| `NaN` / `Infinity` | 变 `null` |
| `Map` / `Set` | 变 `{}` |
| 循环引用 | 抛 TypeError |

## structuredClone

浏览器原生的深拷贝，基于结构化克隆算法：

```js
const copy = structuredClone(obj) // 支持循环引用、Map、Set、Date、ArrayBuffer
```

局限：

- 不能拷贝函数、Symbol、DOM 节点、class 原型方法
- 会丢失原型链（结果为普通对象）
- 不能自定义复制逻辑

所以：**普通数据用 structuredClone，需要保留原型或自定义逻辑时手写**。

::: interview 面试视角
主动说出"JSON 深拷贝的六种丢失"与"structuredClone 不支持函数和原型"，说明你对边界有实际认知，而不是只会背递归写法。
:::
