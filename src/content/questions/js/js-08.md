## 状态机

```
pending ──resolve──> fulfilled
   └─────reject───> rejected
```

三条不可逆规则：

1. 状态一旦确定不可再变
2. `then` 回调**永远异步**执行（微任务），即使已 resolved
3. `then` 返回**新 Promise**，支持链式

```js
const p = new Promise((resolve, reject) => {
  resolve(1)
  reject(2)     // 无效
})
p.then(console.log) // 1
```

## then 的四个规范点

1. 返回值穿透：参数非函数时原值下传
2. 抛错向下传递：任一环抛错，后续 catch 捕获
3. 循环引用：resolve 自身应抛 TypeError
4. thenable 采纳：只允许第一次 resolve/reject 生效

```js
Promise.resolve(1)
  .then((v) => v + 1)
  .then(() => { throw new Error('x') })
  .then(() => console.log('skip'))
  .catch((e) => console.log(e.message)) // 'x'
  .finally(() => console.log('done'))
```

## Promise.all

```js
function promiseAll(list) {
  return new Promise((resolve, reject) => {
    const results = new Array(list.length)
    let count = 0
    if (list.length === 0) return resolve(results)

    list.forEach((item, i) => {
      Promise.resolve(item).then(
        (v) => {
          results[i] = v
          if (++count === list.length) resolve(results)
        },
        reject // 快速失败，第一个 reject 即整体失败
      )
    })
  })
}
```

关键：用**索引**写入结果保证顺序，即使完成顺序不同。

## Promise.race

```js
function promiseRace(list) {
  return new Promise((resolve, reject) => {
    list.forEach((item) => Promise.resolve(item).then(resolve, reject))
  })
}
```

race 的语义是"第一个落定（成功或失败）"，不是"第一个成功"，这是最常被答错的点。

## Promise.allSettled

```js
function allSettled(list) {
  return Promise.all(
    list.map((item) =>
      Promise.resolve(item).then(
        (value) => ({ status: 'fulfilled', value }),
        (reason) => ({ status: 'rejected', reason })
      )
    )
  )
}
```

永不 reject，用于"批量执行、逐个汇总"的场景（如批量保存，需要知道哪些失败）。

## 组合器语义对照

| API | 成功 | 失败 |
| --- | --- | --- |
| `all` | 全部成功 | 任一失败立即 reject |
| `allSettled` | 全部落定 | 永不 reject |
| `race` | 第一个落定 | 同左 |
| `any` | 第一个成功 | 全部失败 → AggregateError |

## 取消与超时

Promises 本身不可取消。标准做法是 `AbortController`：

```js
const controller = new AbortController()
fetch(url, { signal: controller.signal })
setTimeout(() => controller.abort(), 3000)
```

纯 Promise 任务只能"忽略结果"：

```js
function withTimeout(p, ms) {
  let timer
  const timeout = new Promise((_, reject) => {
    timer = setTimeout(() => reject(new Error('timeout')), ms)
  })
  return Promise.race([p, timeout]).finally(() => clearTimeout(timer))
}
```

::: warn race 不等于取消
被超时的请求仍在后台执行、仍消耗资源。真正的取消需要 AbortController 或服务端 token 校验。
:::

::: interview 面试视角
能说清"all 用索引保证顺序"、"race 是第一个落定而非第一个成功"、"race 不是取消"，三点齐全即为高分。
:::
