## 定义

柯里化把接收多个参数的函数转换成"一次接收一个（或部分）参数、返回新函数"的形式：

```js
const add = (a, b, c) => a + b + c
const curried = curry(add)

curried(1)(2)(3)  // 6
curried(1, 2)(3)  // 6
curried(1)(2, 3)  // 6
```

注意柯里化（currying）与偏函数应用（partial application）的区别：柯里化固定"每次一个"，偏函数是"预先填入部分参数"。

## 通用实现

```js
function curry(fn, arity = fn.length) {
  return function curried(...args) {
    if (args.length >= arity) {
      return fn.apply(this, args)
    }
    return curried.bind(this, ...args)
  }
}
```

`fn.length` 是**形参个数**（不含默认值、不含剩余参数），所以：

```js
function f(a, b = 1, ...rest) {}
f.length // 1（只数到第一个默认值之前）
```

这解释了为什么需要显式传 `arity`。

## 支持占位符

```js
const _ = curry.placeholder

function curry(fn, arity = fn.length) {
  return function curried(...args) {
    // 过滤占位符后的实参数量
    const realArgs = args.filter((a) => a !== _)
    if (realArgs.length >= arity) {
      // 用暂存的参数填充占位符
      return fn.apply(this, args.map((a) => (a === _ ? undefined : a)))
    }
    return (...next) => {
      // 把新参数填入前面的占位符位置
      const merged = args.map((a) => (a === _ && next.length ? next.shift() : a))
      return curried(...merged, ...next)
    }
  }
}
curry.placeholder = Symbol('placeholder')
```

占位符的价值：可以"先传后面的参数，再回头补前面的"。

```js
const greet = (greeting, name) => `${greeting}, ${name}`
const g = curry(greet)
g(_, 'Alice')('Hi') // 'Hi, Alice'
```

## 实际用途

### 1. 参数复用

```js
const request = curry((base, path, params) => fetch(base + path, params))
const api = request('https://api.example.com')
const getUsers = api('/users')
```

### 2. 与组合（compose）配合

```js
const compose = (...fns) => (x) => fns.reduceRight((v, f) => f(v), x)
const add = curry((a, b) => a + b)
const double = (x) => x * 2
const addThenDouble = compose(double, add(1))
addThenDouble(3) // 8
```

这也是 `map(add(1))` 能工作的原因 —— `map` 只传一个参数，柯里化后正好匹配。

### 3. 事件处理中的预置上下文

```js
const handle = curry((id, event) => { /* ... */ })
items.map((item) => handle(item.id)) // 返回等待 event 的函数
```

## 性能与取舍

柯里化每次调用都会创建闭包，高频热路径上有开销。多数场景下可读性收益更大，但不要在渲染循环中逐帧柯里化。

::: interview 面试视角
"柯里化就是把多参数函数变成单参数"只是定义。能区分柯里化与偏函数应用、说明 `fn.length` 的局限、并给出组合函数与参数复用的真实场景，才是完整回答。
:::
