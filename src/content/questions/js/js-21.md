## 1. 原生 flat

```js
[1, [2, [3, [4]]]].flat()      // [1, 2, [3, [4]]] —— 默认深度 1
[1, [2, [3, [4]]]].flat(2)     // [1, 2, 3, [4]]
[1, [2, [3, [4]]]].flat(Infinity) // [1, 2, 3, 4]

// flat 会自动跳过空位
[1, , 2].flat() // [1, 2]
```

注意 `flat` 也是**浅层**处理：只展开一层，深层的引用不变。

## 2. 递归实现

```js
function flatten(arr, depth = 1) {
  const out = []
  for (const item of arr) {
    if (Array.isArray(item) && depth > 0) {
      out.push(...flatten(item, depth - 1))
    } else {
      out.push(item)
    }
  }
  return out
}
```

问题：深度大时会爆栈（`Maximum call stack size exceeded`）。

## 3. 循环 + 栈（避免递归爆栈）

```js
function flattenStack(arr, depth = Infinity) {
  const stack = arr.map((v) => ({ v, d: 0 }))
  const out = []
  while (stack.length) {
    const { v, d } = stack.pop()
    if (Array.isArray(v) && d < depth) {
      for (let i = v.length - 1; i >= 0; i--) stack.push({ v: v[i], d: d + 1 })
    } else {
      out.push(v)
    }
  }
  return out.reverse() // pop 是从后往前，需反转恢复顺序
}
```

优点：不受调用栈深度限制；缺点：需要额外空间记录深度，且需处理顺序反转。

## 4. reduce + concat

```js
const flatten = (arr, depth = 1) =>
  depth > 0
    ? arr.reduce((acc, v) => acc.concat(Array.isArray(v) ? flatten(v, depth - 1) : v), [])
    : arr.slice()
```

可读性好，但 `concat` 会反复创建新数组，大数据量下性能较差。

## 5. 用 Generator 惰性展开

```js
function* walk(arr, depth = Infinity) {
  for (const item of arr) {
    if (Array.isArray(item) && depth > 0) yield* walk(item, depth - 1)
    else yield item
  }
}
const flat = [...walk([1, [2, [3]]])]
```

适合"只需要遍历一次、不想分配中间数组"的场景。

## 取舍对照

| 方式 | 时间 | 空间 | 爆栈风险 |
| --- | --- | --- | --- |
| `flat` | 快（原生） | 中 | 无 |
| 递归 | O(n) | 调用栈 O(深度) | 有 |
| 栈迭代 | O(n) | O(n) | 无 |
| reduce+concat | O(n²) 最坏 | 高 | 有 |
| Generator | O(n) 惰性 | O(深度) | 有 |

## 常见错误

```js
// 错误 1：忽略 depth 参数
function bad(arr) { return arr.flat() } // 只展开一层

// 错误 2：用字符串拼接
[1, [2, [3]]].toString().split(',') // ['1','2','3'] —— 类型全变字符串，且无法处理对象

// 错误 3：判断写反
Array.isArray(item) ? out.push(item) : out.push(...flatten(item))
```

::: interview 面试视角
能主动提到"递归会爆栈，用显式栈"这一点，是从"会写"到"考虑边界"的差别。再补上 `flat` 的默认深度与跳过空位行为，就完整了。
:::
