## 优先级（高 → 低）

1. **new 绑定**：`new F()`，this 指向新对象
2. **显式绑定**：`call` / `apply` / `bind`
3. **隐式绑定**：`obj.fn()`，this 指向 obj
4. **默认绑定**：独立调用，严格模式 `undefined`，非严格为全局对象

```js
function F() { console.log(this.tag) }
const bound = F.bind({ tag: 'bind' })
new bound()                       // undefined —— new 覆盖 bind
const obj = { tag: 'obj', F }
obj.F.call({ tag: 'call' })       // 'call' —— 显式覆盖隐式
```

## 隐式绑定丢失

```js
const obj = { name: 'obj', fn() { return this.name } }
const detached = obj.fn
detached()  // undefined —— 退化为默认绑定

setTimeout(obj.fn, 0)   // 同样丢失
;['a'].forEach(obj.fn)  // 同样丢失
```

修法：`bind`、箭头函数包装、或用 `forEach(fn, thisArg)` 传第二参数。

## 箭头函数

```js
const obj = {
  name: 'obj',
  arrow: () => this.name,
  regular() { return this.name }
}
```

差异清单：

| 特性 | 普通函数 | 箭头函数 |
| --- | --- | --- |
| this | 调用时确定 | 定义时从外层词法环境捕获 |
| arguments | 有 | 无（用剩余参数） |
| 可被 new | 可以 | 抛 TypeError |
| prototype | 有 | 无 |
| bind 改变 this | 有效 | 无效 |
| yield / super | 视上下文 | 不能作为 generator |

## 常见坑

```js
// 1. 对象字面量里用箭头当方法
const api = {
  base: '/api',
  get: (url) => fetch(this.base + url) // this 不是 api
}

// 2. 类字段中的箭头函数（每个实例一份）
class A {
  handle = () => { this.count++ }  // 内存换便利
}

// 3. Vue Options API 中 methods 用箭头函数
export default {
  data() { return { n: 0 } },
  methods: {
    inc: () => { this.n++ }  // this 不是组件实例
  }
}
```

## 严格模式的影响

```js
function f() { return this }
f()                    // 非严格：window / globalThis
'use strict'
function g() { return this }
g()                    // undefined
```

ES Module 与 class 内部默认严格模式，所以模块顶层的 `this` 是 `undefined`。
