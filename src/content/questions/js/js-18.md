## 五种方式

### 1. 原型链继承

```js
function Parent() { this.colors = ['red'] }
function Child() {}
Child.prototype = new Parent()

const a = new Child()
const b = new Child()
a.colors.push('blue')
console.log(b.colors) // ['red', 'blue'] —— 引用共享
```

问题：引用属性共享、无法传参、父构造函数提前调用一次。

### 2. 借用构造函数

```js
function Child(...args) {
  Parent.call(this, ...args)
}
```

解决了传参与引用共享，但方法必须在构造函数内定义，无法复用。

### 3. 组合继承

```js
function Child(...args) {
  Parent.call(this, ...args)
}
Child.prototype = new Parent()
Child.prototype.constructor = Child
```

父构造函数被调用**两次**，prototype 上残留一份无用属性。

### 4. 原型式继承

```js
function createObj(o) {
  function F() {}
  F.prototype = o
  return new F()
}
// 等价于 Object.create(o)
```

### 5. 寄生组合继承（ES5 最优）

```js
function inherit(Child, Parent) {
  Child.prototype = Object.create(Parent.prototype)
  Object.defineProperty(Child.prototype, 'constructor', {
    value: Child,
    enumerable: false,
    writable: true,
    configurable: true
  })
  Object.setPrototypeOf(Child, Parent) // 继承静态方法
}

function Child(...args) {
  Parent.call(this, ...args)
}
inherit(Child, Parent)
```

父构造函数只调用一次，原型链干净，静态方法也能继承。

## class extends 的实现

```js
class Child extends Parent {
  constructor(...args) {
    super(...args)   // 等价于 Parent.call(this, ...args)
  }
  method() {
    return super.method() // 在 Parent.prototype 上查找，但 this 仍是子实例
  }
}
```

编译产物本质上就是寄生组合继承，但多了这些语义：

| 差异 | 说明 |
| --- | --- |
| 必须 new | 直接调用抛 TypeError |
| 严格模式 | class 内部始终严格 |
| TDZ | 声明前不可用 |
| 方法不可枚举 | `Object.keys(A.prototype)` 为空 |
| super 必须先调用 | 构造器中 super 之前不能用 this |
| 不能重定义 prototype | 属性不可写、不可枚举 |

## 继承的取舍建议

- 需要传递参数、保留实例属性 → 必须 `Parent.call(this)`
- 需要复用方法 → 方法放在 prototype 上
- 现代项目直接用 `class`，但要知道它的边界（不能用 call 调用、不能把类当函数）
- 更推荐**组合优于继承**：用 mixin 或函数组合替代深层继承链

```js
// 组合：能力可叠加
const CanFly = (Base) => class extends Base { fly() {} }
const CanSwim = (Base) => class extends Base { swim() {} }
class Duck extends CanSwim(CanFly(Bird)) {}
```
