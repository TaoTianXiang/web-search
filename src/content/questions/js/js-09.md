## 一句话

`async/await` 是**Generator + 自动执行器的语法糖**：`await` 等价于 `yield` 加上"自动把结果送回 next()"。

## 手写原理

```js
function run(genFn) {
  const it = genFn()
  return new Promise((resolve, reject) => {
    function step(method, arg) {
      let res
      try {
        res = it[method](arg)
      } catch (e) {
        return reject(e)
      }
      if (res.done) return resolve(res.value)

      // 关键：把 yield 出的值包装成 Promise，等它落定后继续 next
      Promise.resolve(res.value).then(
        (v) => step('next', v),
        (e) => step('throw', e)
      )
    }
    step('next')
  })
}

// 使用
run(function* () {
  const a = yield Promise.resolve(1)
  console.log(a) // 1
  const b = yield Promise.resolve(2)
  console.log(b) // 2
})
```

这段代码就是 Babel/TS 把 `async/await` 降到 ES5 时的核心结构（配合 `__awaiter`/`__generator` 生成器运行时）。

## await 的真实行为

```js
async function f() {
  console.log('a')
  await null
  console.log('b')
}
f()
console.log('c')
// a c b
```

即使 `await` 的是非 Promise 值，也会**让出一次微任务**。规范上 `await x` 等价于：

```js
Promise.resolve(x).then((v) => { /* 后续代码 */ })
```

所以"await 同步值不会让出"是常见误区。

## 错误处理差异

```js
async function a() { return Promise.reject(new Error('x')) }
async function b() { return await Promise.reject(new Error('x')) }

// 在 try 中调用时行为不同
async function test() {
  try { await a() } catch (e) { console.log('caught a') }  // 能捕获
  try { await b() } catch (e) { console.log('caught b') }  // 能捕获
}
```

但如果写成 `return a()`（不带 await），外层 try 捕获不到，因为 reject 发生在返回的 Promise 上。

::: tip 唯一需要 return await 的场景
就是在 try/catch 内部希望捕获错误，并同时返回结果时。其他场景 `return promise` 更快（少一次微任务）。
:::

## 串行 vs 并行

```js
// 串行：总耗时 = a + b
const a = await fetchA()
const b = await fetchB()

// 并行：总耗时 = max(a, b)
const [ra, rb] = await Promise.all([fetchA(), fetchB()])
```

注意：`Promise.all([fetchA(), fetchB()])` 中两个请求是**同时发起**的；而逐个 await 是等第一个完成才发第二个。判断标准是"两个请求之间是否有数据依赖"。

## 并发上限调度

```js
async function pool(tasks, limit) {
  const results = new Array(tasks.length)
  let cursor = 0

  async function worker() {
    while (cursor < tasks.length) {
      const i = cursor++
      results[i] = await tasks[i]()
    }
  }

  await Promise.all(Array.from({ length: Math.min(limit, tasks.length) }, worker))
  return results
}
```

要点：共享游标避免重复领取，`while` 让 worker 复用而不是一次性。

能写出 run(gen) 自动执行器，并说明"await 非 Promise 也让出微任务"，就可以判断你真的读过降级产物而不是只看过文档。
:::
