## 基础语法

```ts
type A<T> = T extends string ? 'string' : 'other'

type R1 = A<'x'>      // 'string'
type R2 = A<number>   // 'other'
```

`T extends U ? X : Y` 的含义是"T 是否可赋值给 U"（不是"是否相等"）。

## infer：在模式中捕获类型

```ts
// 1. 提取 Promise 内部类型
type Unwrap<T> = T extends Promise<infer U> ? U : T
type A = Unwrap<Promise<number>>         // number
type B = Unwrap<Promise<Promise<string>>> // Promise<string>（只剥一层）

// 2. 提取函数返回类型
type Ret<T> = T extends (...args: any[]) => infer R ? R : never

// 3. 提取数组元素类型
type ElementOf<T> = T extends (infer E)[] ? E : never
type C = ElementOf<string[]>   // string

// 4. 提取元组首元素
type First<T> = T extends [infer F, ...any[]] ? F : never
type D = First<[1, 2, 3]>   // 1

// 5. 提取元组末元素
type Last<T> = T extends [...any[], infer L] ? L : never

// 6. 提取对象某个键的值类型
type ValueOf<T, K extends keyof T> = T extends Record<K, infer V> ? V : never
```

infer 可以出现多次，并组合成新类型：

```ts
// 交换元组的前两个元素
type Swap<T> = T extends [infer A, infer B, ...infer Rest] ? [B, A, ...Rest] : T
type E = Swap<[1, 2, 3]>   // [2, 1, 3]

// 提取对象的值组成的联合
type ValueUnion<T> = T extends Record<string, infer V> ? V : never
```

## 分布式条件类型

触发条件：**裸类型参数** + 传入联合类型。

```ts
type ToArray<T> = T extends any ? T[] : never
type R = ToArray<string | number>
// = string[] | number[]，不是 (string | number)[]
```

阻止分布：

```ts
type ToArrayNoDist<T> = [T] extends [any] ? T[] : never
type R2 = ToArrayNoDist<string | number>   // (string | number)[]
```

为什么要阻止？因为想"整体判断"而不是"逐个判断"：

```ts
// 想要：只有当 T 完全是 string 时才返回 'all-string'
type IsAllString<T> = T extends string ? true : false
type A = IsAllString<'a' | 'b'>   // true | true → true（碰巧对）
type B = IsAllString<'a' | 1>     // true | false → boolean（不是想要的结果）

// ✅ 用元组包裹
type IsAllStringFixed<T> = [T] extends [string] ? true : false
type C = IsAllStringFixed<'a' | 1>   // false
```

## 三个实用例子

### 1. 从函数类型中提取参数名与类型

```ts
type Params<F> = F extends (...args: infer P) => any ? P : never
type P = Params<(a: string, b: number) => void>   // [string, number]
```

### 2. 递归展开嵌套数组

```ts
type Flatten<T> = T extends (infer U)[]
  ? U extends any[]
    ? Flatten<U>
    : U
  : T

type F = Flatten<number[][][]>   // number
```

### 3. 把联合转成交叉

```ts
type UnionToIntersection<U> =
  (U extends any ? (x: U) => void : never) extends (x: infer I) => void
    ? I
    : never

type I = UnionToIntersection<{ a: 1 } | { b: 2 }>   // { a: 1 } & { b: 2 }
```

原理：把每个成员放进函数参数位置（逆变位置），多个候选会被推断为交叉。

### 4. 按条件筛选对象键

```ts
type PickByValue<T, V> = {
  [K in keyof T as T[K] extends V ? K : never]: T[K]
}

interface User { id: string; age: number; active: boolean }
type StringFields = PickByValue<User, string>   // { id: string }
```

## 常见陷阱

```ts
// ❌ 直接对 any 做条件判断
type Bad<T> = T extends any ? 'a' : 'b'   // 恒为 'a'

// ❌ infer 在协变位置被推断为联合
type InferUnion<T> = T extends { a: infer A; b: infer B } ? A | B : never

// ❌ 递归过深导致类型实例化过深
type Deep<T> = { [K in keyof T]: Deep<T[K]> }   // 循环引用类型会报错
```
